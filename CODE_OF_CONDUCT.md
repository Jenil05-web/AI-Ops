# 📜 Code of Conduct

</div>

<br/>

## Our Standard

This project is a space for building and learning. Treat it that way:

- **Be respectful.** Disagree with ideas, not people.
- **Be constructive.** "This is wrong" is a start, not a finish — explain why, and if you can, suggest better.
- **Be patient.** Not everyone here has the same experience level. That's fine. That's the point.
- **No harassment, personal attacks, or discriminatory language** — of any kind, toward anyone, ever.

<br/>

## Not Okay

- Insults, name-calling, or dismissive behavior toward other contributors
- Publishing others' private information without consent
- Sustained disruption of issues, PRs, or discussions
- Any conduct that would reasonably make someone feel unwelcome or unsafe

<br/>

## Enforcement

Violations can be reported by opening a private message to the maintainer via GitHub, or by flagging a comment/issue directly. Maintainers reserve the right to remove comments, close issues/PRs, or block contributors who don't follow this standard — proportionate to the severity and pattern of behavior.

<br/>

## Scope

This applies to all project spaces — issues, pull requests, discussions, and any other official communication channel tied to this repository.
